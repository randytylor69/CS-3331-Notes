# Regular or not?
---
### Proving use closure properties

For $L$ that aren't compatible with pumping, we can take its closure properties and analyze the result with pumping:

- $\neg L = L'$. Taking the negation because possibly $L' = A \cup B$ and we can remove $B$ to only test on $A$. 
- $L \cap \text{some regex} = L'$

In both cases we get a new language $L'$ which will be significantly easier to prove with pumping. 

# Equivalence Relations
---
#### Give equivalence classes for Non-Regular Languages

1. Strings already accepted
2. Strings would be accepted with $z$
3. Strings wouldn't be accepted with $z$
4. Strings not accepted 

#### Prove each class is distinctive of the other using MH

- The minimal DFA has $n$ states -> $n$ equivalence classes. 
- List a finite set of all classes: $S = \{\epsilon, n_i, n_{i+1}, ... \}$
- Choose 2 arbitrary classes $n^i$ and $n^j$ and prove they're distinctive using suffix $z$ 
- Sincere any 2 arbitrary classes in $S$ are distinctive, then we have $n$ distinctive classes
